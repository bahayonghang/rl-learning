## 已发现、已修正并重新读取确认

### 1. 时间划分公式需要同时限制验证集的末端

**位置：** `advanced-guides.ts` 第 20 章“按时间和工况划分，阻断窗口泄漏”。

原先 `max t(train) < min t(validation) < min t(test)` 不足以排除验证集与测试集重叠，例如验证集可以继续延伸到测试集内部。

现已改为两个条件：

\[
\max t(\mathcal D_{tr})<\min t(\mathcal D_{va}),\qquad
\max t(\mathcal D_{va})<\min t(\mathcal D_{te}).
\]

正文继续保留输入窗口、目标跨度、标签延迟等依赖范围的隔离要求。修正正确。

### 2. 请求增量与实际执行增量必须在公式中分开

**位置：** `advanced-guides.ts` 第 15 章最后一个步骤；第 21 章符号表与奖励式。

原先第 15 章直接用策略候选更新实际 SP，第 21 章把 a 定义为候选，却在描述物理平滑性的奖励中使用同一符号，容易让读者把门控拒绝的候选当作已执行。

现已明确 `a_req → Gate → a_exec`，实际 SP 更新和动作平滑项使用 `a_exec`，与工作台保持一致。修正正确。策略概率仍针对生成的请求动作定义；门控后的复合策略与候选策略在建模时需要继续区分。

### 3. 60 分钟时的单条奖励与之后的尾部价值差一次折扣幂

**位置：** `primer.ts` 折扣单元，`primer-calculators.ts` 折扣计算器，`glossary.ts` 折扣因子。

既有记号为

\[
G_t=\sum_{k\ge0}\gamma^k r_{t+k+1},
\]

且第一条奖励对应动作后第一个 5 分钟周期。因此 60 分钟时收到的第 12 条奖励系数是 `γ^11`，而 `γ^12` 是 12 步之后的尾部回报系数。原标签混淆了两者。

现已添加前 H 步与尾部的分解，并将计算器、图轴和词汇解释改为尾部价值，明确第 12 条奖励的 `γ^11`。修正正确。以 γ=0.9 为例，两者分别约为 0.3138106 和 0.2824295。

### 4. 模型滚动误差界需要包含闭环动作响应

**位置：** `advanced-guides.ts` 第 23 章“推导多步误差为什么会累积”。

`e_{k+1} ≤ L e_k + ε` 在同一动作序列下可以使用过程对状态的 Lipschitz 上界；若策略分别根据真实和预测状态选择不同动作，还需要包含策略反馈的敏感度，不能只用过程状态项。

现已说明相同外部扰动、相同动作序列与闭环策略两种情况；闭环 L 可由 `Lx + La Lπ` 上界。修正正确。若未来扩展到随机策略的路径误差界，还需说明策略噪声的配对方式或改用分布误差口径；当前确定性教学示意无需展开。

## 集成时补充修正的小项

以下三项已由统一编辑者在最终集成中修正；数值内核没有因此改变。前两项调整展示与解释，第三项补齐级数的数学条件。

### A. tanh 计算器的“显示等式”使用了过度舍入的中间量

**位置：** `src/primer-calculators.ts`，density 分支的 `equation`，审阅时约第 74 行。

内部函数正确，但展示把 `a=tanh(u)` 先保留 4 位小数，再把这个值放进一个等式中。当 u=3、σ=1 时：

- 精确 `a ≈ 0.9950547537`，显示为 `0.9951`。
- 内部正确 `log p_A ≈ −0.8002815240`，显示为 `−0.8003`。
- 按显示的 `−5.4189 − log(1−0.9951²)` 手算，得到约 `−0.7910741`。

靠近边界时 Jacobian 对中间舍入敏感，差异超过最终显示精度，初学者会怀疑公式或自己的计算。

**已修正：** 公式保留 `tanh(3.0)`，从高斯密度表达式直接写到近似结果，数字结尾用 `≈`；说明表格数值四舍五入、计算仍保留原精度。无需修改数值内核。

### B. tanh 边界密度的叙述需限定比较对象

**位置：** `src/content/primer.ts` 密度单元中“靠近边界……密度因此变高”，审阅时约第 336 行。

这里应表达的是：**相对同一个 u 处的原高斯密度**，变换后密度除以小于 1 的 Jacobian，因此被放大。不能推断“动作越靠近 ±1，其绝对密度就必然越高或发散”。对任意固定有限均值、正有限方差的高斯，二次衰减最终超过 Jacobian 的指数放大，tanh 推送密度在极限边界仍趋向零。

**已修正：** 限定为同一个 u 处的相对密度放大，并说明有限参数高斯的变换密度在边界趋向零。同句改为“tanh 后候选动作的分布”，补充后续安全门会进一步改变实际执行分布。

### C. 无限折扣级数给出完整条件

**位置：** `src/content/primer.ts` 折扣单元“奖励有界且 γ<1”。

RL 语境通常默认 γ 非负，计算器也限制在 `[0,0.999]`，因此当前可操作范围没有数值错误。不过独立数学准备页可以把条件直接写成 `0 ≤ γ < 1`，避免把单独的 `γ < 1` 误读成收敛充分条件。一般几何级数的条件是 `|γ| < 1`。

**已修正：** 数学准备正文明确写为 `0 ≤ γ < 1`。这是局部条件补全，不改变计算器输入范围。

## 集成复核补充

另一次独立集成检查与真实浏览器验收发现并修复了三个具体问题：

1. **导出符号表的列完整性。** LaTeX 范数中的 `\|` 与 Markdown 表格的竖线转义叠加，会让符号、名称和释义错列。导出时先把数学竖线改为命名的 `\Vert` / `\vert`，再处理表格文本。新增回归检查使用 Marked 实际解析全部 24 组符号表，核对列数、名称和释义；没有只检查字符串片段。
2. **逐步推导的键盘焦点。** 原步骤按钮随内容替换而移除，键盘用户容易失去当前位置。现在下一步绘制完成后将焦点放在 `tabindex=-1` 的新标题；窄屏浏览器中用 Enter 前进，确认焦点落在第 2 / 6 步的新标题。
3. **窄屏时钟宽度。** 工作台在最窄断点同时设置 `width:100%` 和左侧 margin，造成页面宽于视口。改为扣除 margin 的 `calc(100% - 42px)`；375 CSS px 内容宽度下重新检查，页面宽度为 375 px，工作台交互继续正常。
