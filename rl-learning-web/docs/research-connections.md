# 烧成研究连接与高级推导核验记录

本记录对应 `src/content/advanced-guides.ts` 与 `src/content/research.ts`。两者是交互阅读器与全书导出的纯内容数据，不修改现有工业环境、观测维数、动作接口或安全阈值。

## 内容范围

- 第 13–24 章各有烧成情景、决策问题、直觉、符号、至少 5 步推导、数值例子、解释“为什么”的段落，以及 3 个选项各自的反馈。
- 12 章合计 71 个推导步骤；131 条公式及符号表达已经以 KaTeX 严格模式逐条解析。
- 引导情景全部采用上层 CV 设定值增量。没有把煤、风、阀门等底层执行器开放给策略，也没有新增可交互生产连接。
- 研究页提供 6 项可证伪假设、数据字段字典、按时间与工况划分协议、基线、消融、失败标准和分阶段交付建议。
- 研究设计明确区分公开文献、项目接口与待执行实验；不填入未运行的基线结果，不把网页演示或世界模型推演表述成现场节能。
