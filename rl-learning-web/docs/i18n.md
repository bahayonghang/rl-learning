# 双语内容与语言扩展

RL Atlas 当前注册 `zh-CN`（简体中文）和 `en`（English）两个完整版本。语言选择覆盖正文、推导、练习答案、研究专题、交互解释和界面，不只是导航标签。内容在仓库内维护，切换时不会调用远程翻译服务。

本说明依据当前的 [语言接口](../src/i18n.ts)、[内容加载器](../src/content/localized.ts)、[页面入口](../src/main.ts)和 [持久化实现](../src/storage.ts)。启动、部署和工业边界见 [中文 README](../README.md)与 [English README](../README.en.md)。

## 当前内容范围

以下数量从两种语言实际加载的数据计算，两种版本一致：

| 内容 | 每种语言的数量 |
|---|---:|
| 课程模块 / 完整章节 | 7 / 24 |
| 水泥情景推导器 / 推导步骤 | 24 / 154 |
| 数学准备单元 | 8 |
| 概念与符号词条 | 36 |
| 独立研究专题 | 9 |
| 图解库 | 28：21 张学术概念图解、7 幅既有插画 |
| 去重资源 / 保留的引用 ID | 59 / 77 |

14 个算法实验与烧成工作台也提供双语界面、参数说明和反馈。21 张新概念图覆盖 11 章、9 篇研究与学习路线；7 幅既有插画由 4 幅研究概念图、3 幅原始课程导览图组成。同一图像使用简短英文标签，并配相应语言的标题、alt、分区说明和准确关系说明。独立站点标识不计入图解数量。图像不承担精确公式、定量曲线或网络拓扑说明。

## 内容由谁负责

| 位置 | 契约 |
|---|---|
| `src/i18n.ts` | 注册语言、显示名、HTML `lang` / `dir`；提供 `getLocale`、`setLocale`、`localize`、`text`、数字格式与下载文件名工具 |
| `src/content/index.ts` 及中文内容文件 | 中文模块、24 章、来源、推导、数学准备与词典 |
| `src/content/en/` | 相同稳定 ID 的完整英文内容；章节、练习、代码注释、图片说明和反馈均须完成翻译 |
| `src/content/localized.ts` | `ContentBundle` 形状、英文分块加载、当前版本数据与查询函数 |
| `src/research/` | 研究标题、摘要与完整正文的双语记录；来源说明区分中文与英文 |
| `src/concept-plates.ts` / `src/figures.ts` | 稳定图片注册表、双语标题/alt/分区/关系说明与图库元数据 |
| `src/source-catalogue.ts` | 按 URL 合并资源，同时保留所有来源 ID 和关联章节/研究页 |
| `src/learning.ts`、计算器、实验、工作台、目录与页面入口 | 控件、错误与状态提示、判断反馈、可访问名称等界面文案 |
| `scripts/export-book.ts` 与工作台模型附录 | 生成对应语言的完整教材和研究综述 |

中文内容在初始包中可用；英文通过动态导入加载，成功后复用加载结果。`activateContent` 统一切换章节、模块、来源、推导、数学单元与词典。页面应使用这些活动数据查询接口，避免绕过内容加载器直接把中文正文显示到英文页面。

研究正文目前使用 `BiText` / 双语字段保存，未放进 `ContentBundle`。新增语言时，两种数据组织方式都需要覆盖。旧研究来源别名也要进入相应内容包，否则正文引用虽然存在，资源库仍可能丢失映射。

## UI 文案与稳定身份

简短界面文案可以使用当前的双语 helper：

```ts
import { text, localize } from './i18n';

const label = text('展开全部步骤', 'Expand all steps');
const title = localize({ 'zh-CN': '条件期望', en: 'Conditional expectation' });
```

`text(zh, en)` 是明确的双语接口，不能只在语言注册表里加一个第三语言就继续使用。扩展时应把它改为覆盖所有注册语言的消息记录或等价接口，并逐项迁移调用者。`editionFilename` 当前也区分中文无后缀和英文 `.en`，需要一并扩展。

章节 ID `01`–`24`、模块 ID、实验 ID、研究 ID、来源 ID、公式变量和路由身份不翻译。完成状态因此可以跨中英文使用。`Chapter.level` 的 `入门/进阶/实践` 和词典分组的中文值是既有枚举键；保留键，显示时使用本地化标签。论文标题、作者、DOI 与 URL 保持可检索的来源身份，解释性注释另行翻译。

两种语言的推导应保留相同假设、数值、公式与练习逻辑。公式中的自然语言标签、代码注释、概念图的可选择读图说明和答案解释也属于可见内容。语言无关的原始 LaTeX 或符号可以共用；不能把中文正文直接作为英文正文，或用简短概述替代完整章节。修改一方的数学错误时，另一方应同步修正。

## 切换时发生什么

1. 语言控件触发 `changeLocale`，等待目标内容包完整加载。
2. 激活内容包并设置当前语言，保存偏好；更新根元素的 `lang` / `dir` 和页面文案。
3. 重新渲染当前 hash 路由，并尝试恢复此前的滚动位置。

重新渲染会调用上一页的清理函数，再挂载新页面。因此，实验参数、计算器输入、推导当前步骤、工作台时钟和运行历史等组件内部状态可能重置；目前没有跨语言实验快照机制。稳定的页面 ID 不等于临时交互状态保持。比较两种语言的同一实验，应记录种子和参数后重新运行。

全局搜索使用当前语言的正文、推导、数学准备、研究和词典。部分工艺术语和研究关键词保留双语别名，方便查找；这不是对另一语言全部正文的跨语言语义搜索。资源库和图解库各有自己的分类与关键词筛选。

## 保存的数据与旧版本

当前 `LearningState` 只包含：

```ts
{
  version: 2,
  completed: ['01'],
  theme: 'light',
  textSize: 'normal',
  locale: 'zh-CN'
}
```

数据保存在当前站点来源的 `rl-atlas-preferences-v2` 键。只有新键不存在时，加载器才读取旧键 `rl-atlas-learning-v1`，并只提取合法完成 ID、主题、字号与已注册语言。旧键不会删除；旧笔记、收藏、上次阅读等字段不恢复、不展示，也不写入新状态。

目前没有笔记、收藏、继续阅读入口或学习数据 JSON 导入/导出流程。教材、章节、路线清单和原图下载仍然提供，它们属于学习材料下载。不同浏览器、端口、域名和设备之间不自动同步。存储被禁用或写入失败时，不能把当前会话中的界面变化表述为已持久保存。

## 增加一种语言的完整步骤

1. **先完成内容包。** 对齐模块、24 章、24 个推导器、8 个数学单元、词典与全部来源说明；逐项检查练习答案、选项反馈和代码内可见注释。保留相同 ID、数字和数学含义。
2. **补齐研究与交互文案。** 扩展研究正文与类型、图注、资源分类、实验、工作台、计算器、错误提示、可访问标签、搜索元数据和路线清单。不要只翻译页面标题。
3. **扩展语言接口。** 更新 `Locale`、注册表、内容加载分支、`Localized` / `BiText`、UI 消息接口、枚举显示映射、数字格式和文件名工具；检查 `lang`、`dir` 与目标语言的排版需求。完成前不要把语言暴露到选择器。
4. **增加模型附录与导出。** 为新语言准备完整工作台模型说明，让导出脚本包含正文、所有折叠步骤、练习反馈、研究、词典、图片说明、代码链接和来源别名。导出文件不能用中文内容填空。
5. **验证数据与页面。** 先更新导出，再运行内容/数值检查、类型检查和构建；在实际浏览器核对长标题、公式、表格、图片及放大查看、深浅主题、窄屏导航、搜索、语言切换和组件清理。

## 导出与维护命令

从 `rl-learning-web/` 执行 `just check`，依次准备依赖、导出、测试、类型检查和构建。只更新长文可用 `just book` 或 `npm run export:book`。`npm run build` 自身不会更新生成的 Markdown。

每次导出生成中英文各三份文件：`docs/rl-atlas-tutorial[.en].md`、`public/rl-atlas-tutorial[.en].md`、`public/code/research-review[.en].md`，共六份。修改来源文件，勿直接维护生成长文。URL 去重后仍须保留所有引用 ID；两种语言的资源映射应一致。

翻译核验记录见 [基础内容](translation-foundations.md)与 [进阶内容](translation-advanced.md)。研究推理审查见 [数学审查记录](review-mathematics-v2.md)，原始三幅导览插图的来源说明保留在 [illustrations.md](illustrations.md)。这些记录描述各自核验范围；自动检查不能替代实际页面验收。
