# RL Atlas：评审核验与体验优化规划

日期：2026-11-14。基线：`ca36ca3`（已 fetch 确认远端 main）。输入为用户提供的《RL Atlas Website Review: Design, Function and Learning Experience》。原报告明确只依据一张 Overview 截图；下面区分截图判断与源代码事实。

## 目标与保留的决定

让读者迅速知道这是“面向流程工业运行决策的强化学习教程”，按已有知识找到入口，理解每种学习工具的用途，并在中英文、明暗主题和手机上清楚阅读与操作。

保留橙色视觉语言、完整双语内容、中文图与英文图切换、交互公式案例。延续用户此前要求：不恢复笔记、收藏、“继续上次学习”或阅读历史。现有章节完成记录可以明确展示。

## 学习结构与实现

导航分为开始与学习、动手验证、研究与查阅。数学准备补概率、期望和梯度；正文章节解释 RL 原理与推导；公式案例完成一次数值代入；算法实验观察参数或迭代行为；水泥决策工作台把动作、过程响应、延迟化验和安全门控组合成一次教学推演。

三条路径面向已有 ML 基础但初学 RL、熟悉过程控制、已掌握 RL 想研究工业决策的读者。选择路径通过 URL 表达，不新增行为记录。用时是规划估计，不是遥测。保留六周/八周路线，并修正原下载始终泛称“6–8 周”的问题，使下载匹配当前选择。

首页保留已有生成图；解释使用语义化 HTML，与图像分离，因此可以翻译、选择文字和键盘操作。主题选择修改呈现属性，不重挂载页面，从而保持正在计算的输入和工作台状态。

## 本轮落地结果

- 首页与路线页从 `main.ts` 提取为独立视图，导航使用 `navigation.ts` 统一名称、分组与用途。
- `#/roadmap/ml`、`#/roadmap/control`、`#/roadmap/rl` 提供三个起点；进度只统计有效、去重的手动章节完成记录。六周和八周安排各覆盖 24 章一次，下载反映当前周数、语言、入口和完成状态。
- 新访客默认跟随系统，旧的显式浅色/深色偏好继续生效；切换主题不重新挂载计算器和工作台。
- 首页图解在不超过 760 CSS px 的布局中默认折叠，桌面默认展开。在 375px 测试框架中，扣除滚动条后的正文宽度为 360px；中文学习入口约在 653px，英文约在 766px，没有页面横向溢出。
- 新增[来源、引用与复用说明](reuse-and-citation.md)，更新两种语言的 README 和维护规范。

完整命令结果、交互检查、截图和验证边界见[本轮验证记录](experience-review-verification.md)。未新增依赖，未更改教材正文、数值内核、工业执行约束或 `ref/`。

## 验证依据与边界

- [W3C WCAG 2.2：Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：普通文本目标至少 4.5:1，大字至少 3:1。
- [W3C WCAG 2.2：Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：一般指针目标至少 24×24 CSS px，存在间距等例外；本次主要操作尽量 40–44px。
- [MDN：prefers-color-scheme](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-color-scheme)：媒体查询感知系统主题，显式偏好优先。

验证改动和代表性回归路径，不把局部检查描述为全站 WCAG 认证。截图不能证明公式正确或模拟可信，相关证据来自独立数值测试和浏览器验收。完成记录是用户手动标记，不能等同于知识掌握评估。
