# RL Atlas 原创介绍图

本项目使用内置 **imagegen** 为课程重新生成三幅介绍插图。生成结果作为项目资源落地后，由 PNG 转为 WebP 压缩；保留完整构图与 **1672 × 941 px** 尺寸，没有用代码重画原文配图。

这些图片负责概念引入与视觉叙事。公式、精确关系、算法流程和可量化图表分别由 KaTeX、Mermaid 和真实数值实验表达。

## 共同的创作方向

以浅奶油纸面、深蓝墨线和低饱和水彩为主要语言，辅以绿色与陶土色。机器人作为学习者，与笔记、网格世界、多臂老虎机、神经网络符号和回转窑概念场景联系起来。保持手绘教育插画的亲近感，同时让画面留有足够空间供网页正文组织信息。

图中不放大段中文、不生成公式、不画伪造的训练曲线，也不将手绘连线当作精确算法证明。第一幅只使用简短题字 **“RL ATLAS”**；图片之外的中文标题、解释和出处由 HTML 正文提供，便于搜索、缩放与辅助技术读取。

## 生成提示词摘要

以下是本轮实际创作提示的语义摘要，记录主题、画面语言和约束，便于后续保持系列一致；不是对原推文图片的逐像素复刻。

### 1. Journey · 课程总览

**用途：** 强化学习教程首页与总览图。

**提示摘要：** 横向教育插画，奶油色纸张背景，深蓝墨水线稿配柔和水彩。一个机器人学习者穿行于探索、网格决策、学习笔记与神经网络象征之间，远处自然衔接工业回转窑场景。表达从一次行动、反馈和学习走向长期决策的旅程。构图清晰、适合网页主题图，文字仅为“RL ATLAS”。不加入数学公式、复杂标签、水印或虚构数据图表。

**文字替代说明：** 机器人围绕网格世界、探索装置和学习笔记理解反馈，画面逐渐连接到神经网络与工业系统。

![课程总览介绍图](../public/images/journey.webp)

### 2. Foundations · 基础与探索

**用途：** 展示探索、回报与价值学习的直觉入口。

**提示摘要：** 与总览一致的深蓝手绘墨线与水彩，温暖浅色背景。机器人学习者研究网格世界、多臂老虎机与打开的笔记，将试探不同选择、观察反馈和记录经验融入一个具体学习场景。保持画面轻盈，主题对象清楚，不用密集文字、数学表达式或精确流程箭头承载知识。

**文字替代说明：** 机器人在老虎机、网格和笔记之间比较不同选择，形成探索与价值估计的概念场景。

![基础与探索介绍图](../public/images/foundations.webp)

### 3. Industry · 工业决策

**用途：** 将通用强化学习连接到流程工业研究。

**提示摘要：** 机器人研究者与工程师围绕回转窑概念模型、控制台和研究笔记协作，保持深蓝墨线、奶油纸面与柔和水彩的系列风格。表现理解工况、讨论候选设定值和审查模型的研究过程。画面为概念性工业教育插图，不出现现场节能数字、认证标记或可直接执行的工艺参数，不承担真实设备结构图的精度要求。

**文字替代说明：** 研究者和工程师围绕烧成系统模型讨论决策，将模型可信度、控制层级与执行边界放在同一研究情境中。

## 与原推文的关系

原推文的课程总览、模块卡片和手绘教学图帮助确定了“先建立整体直觉，再逐项解释机制”的方向。本项目的三幅图是新的场景与构图，没有发布原作者的介绍图、平台截图、购买二维码或会员宣传图。原文中需要精确表达的知识关系被独立重建为 Mermaid 图，具体公式由正文呈现。

本项目也没有把生成插画伪装成真实生产照片或工程图。工业场景用于引出案例，正式观测、动作、成本和安全门约定以章节正文与仓库规范为准。

## 后续更新约定

1. 先确定图片承担的教学主题与摆放位置，再调整构图；不要让一张插画同时充当课程地图、公式表与数据图。
2. 延续纸面、墨线、水彩和角色语言，让系列视觉统一。
3. 涉及公式、图表、阈值与算法关系时，改用可审查的代码图或排版文本。
4. 生成新版本后检查人物、物件、文字与构图，保留来源说明；网页引用必须指向项目内最终资产。
5. 更新最终文件时同步修改本清单中的尺寸、大小和文字替代说明。
