# RL Atlas：来源、引用与复用 / Sources, citation and reuse

## 中文

RL Atlas 是面向流程工业运行决策的强化学习教程，以水泥烧成的教学案例串联数学、算法和研究建模。源码与内容可在 [项目仓库](https://github.com/bahayonghang/rl-learning/tree/main/rl-learning-web) 查看。

引用教程时，请注明项目名称、仓库地址、实际访问日期和使用的 Git 提交版本，例如：

> RL Atlas contributors. *RL Atlas: Reinforcement learning for process decisions*. https://github.com/bahayonghang/rl-learning/tree/main/rl-learning-web . Version: <使用的 commit SHA>; accessed: <访问日期>.

如引用某个学术结论，请优先引用正文链接的原始论文或教材。教程不是这些论文的作者，也不替代原始研究证据。论文与资源页区分理论、教学材料、仿真实验及第一方运行报告；学习案例中的推演结果不代表现场节能效果。

当前仓库尚未声明项目级 LICENSE。本页只说明来源与引用方式，不额外授予内容、代码或图片的复用许可。需要转载或分发时，应向项目维护者确认许可；外链资料按各自权利人的条件使用。插图来源及生成说明见 [illustrations-v2.md](illustrations-v2.md) 与 [concept-plates.md](concept-plates.md)。

## English

RL Atlas teaches reinforcement learning for process-industry decisions through cement-process examples. The [repository](https://github.com/bahayonghang/rl-learning/tree/main/rl-learning-web) provides the source and tutorial content.

When citing this tutorial, include its title, repository URL, the Git commit you used and your access date. The example above intentionally leaves the version and date for the reader to fill in accurately. For a scientific claim, cite the original paper or textbook linked from the relevant chapter; the tutorial does not replace the original evidence.

The repository does not currently declare a project-level LICENSE. This page documents provenance and citation; it does not grant additional reuse rights. Confirm redistribution or adaptation terms with the project maintainer, and follow each external source's own terms. Illustration provenance is documented in [illustrations-v2.md](illustrations-v2.md) and [concept-plates.md](concept-plates.md). Teaching rollouts do not establish real-plant energy savings.
