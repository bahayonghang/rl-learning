# Design

Keep the current English asset URLs as stable canonical identities. Add Chinese siblings under public/images/diagrams/zh-CN/ and public/images/zh-CN/. A centralized image-language resolver maps zh and zh-* to Chinese and every other language to English. The trusted figure recognizer accepts only registered English/Chinese local paths; gallery IDs remain unchanged. Raw authored references may stay canonical while rendering/export resolves the requested edition consistently. Neutral illustrations may share original bytes only after image inspection confirms absence of text.

Use built-in imagegen text-localization edits, retaining compact composition, icons, visual grouping and scientific meaning. Preserve Latin algorithm acronyms and mathematical symbols where conventional, translate all explanatory wording. Persist per-asset exact prompts and visual reviews.

Build reusable typed formula-case definitions with pure numerical solvers and explicit input validation. A bilingual UI presents scenario, named parameters, formula, substituted values, intermediate steps, outcome and interpretation. Reuse existing kernels where mathematically appropriate; never modify industrial safety thresholds or original simulator contracts. Keep calculation components independent of routing so they can mount in chapters and a dedicated cases catalogue. Export complete default worked examples as readable Markdown; static exports do not pretend to be interactive.

Parallel ownership: image workers write only their assigned assets/provenance; formula worker writes new formula modules/tests/docs; root owns localization integration, routing, search, export glue, existing tests, QA and delivery. No new package dependencies.
